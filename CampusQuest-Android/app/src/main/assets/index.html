Catatan penting

Hal yang perlu diketahui saat mencoba prototipe.

Pembayaran kantin pada prototipe ini belum diverifikasi otomatis dari QRIS. Kasir memasukkan nominal dan mencatat transaksi secara manual. Jangan gunakan data ini sebagai bukti pembayaran sungguhan.
Untuk uji NFC fisik, buka halaman ini di Chrome Android melalui HTTPS. Web NFC tidak tersedia di semua browser/perangkat dan biasanya tidak berjalan jika HTML hanya dibuka sebagai file lokal.

Daftar & Tulis NFC

Daftarkan mahasiswa, tulis data gelang, lalu uji pemindaian.

Privasi: karena kamu meminta NIM, prototipe ini menulis NIM bersama token acak ke tag NFC. NIM tetap dapat dibaca oleh perangkat yang kompatibel; token acak tidak membuat isi tag anti-salin. Untuk produksi, lebih aman menulis token acak saja dan menyimpan NIM di sistem dengan akses terbatas.
